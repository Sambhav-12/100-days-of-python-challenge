# Day 16: Introduction to Object-Oriented Programming (OOP) 🏗️

An introductory module focusing on the transition from Procedural Programming to Object-Oriented Programming (OOP) paradigms in Python.

## 🚀 Core Concepts Covered
- **Procedural vs. Object-Oriented Programming:** Understanding the shift from function-driven, top-down code execution to data-driven, state-encapsulated design.
- **Classes & Objects:** Defining the blueprint (Class) vs. the concrete instance (Object) in memory.

# Day 18: Turtle Graphics & Procedural Art 🎨

Explored Python's built-in `turtle` module to practice object manipulation, state configuration, event-driven screens, and algorithmic visual rendering.

## 🚀 Key Concepts Implemented
- **Dynamic Geometry Rendering:** Used loop variables to dynamically compute turn angles (`360 / n`) for multi-sided polygons (Triangles through Decagons).
- **Random Walk Simulation:** Combined continuous random choices (`random.choice`) across heading, speed, and line-weight vectors to simulate state displacement.
- **RGB Tuple Operations:** Initialized `colormode(255)` to generate dynamic RGB color tuples via `random.randint()`.
- **Spirograph Algorithm:** Constructed a modular function to offset headings incrementally across a complete 360° circle execution cycle.

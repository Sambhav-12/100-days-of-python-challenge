# Day 17: Custom Class Constructor & Quiz Application 🧠

A CLI-based True/False quiz engine built from scratch to demonstrate custom class instantiation, constructor initialization (`__init__`), attribute binding, and state-driven methods.

## 🚀 Key OOP Concepts Implemented
- **Custom Constructors (`__init__`):** Initialized instance attributes (`q_text`, `q_answer`) dynamically upon object creation.
- **Data Object Transformation:** Converted raw key-value dictionary records into a collection of structured `Question` class instances.
- **Encapsulated Game Loop:** Built `QuizBrain` to encapsulate flow-control logic (`still_has_questions()`), track running metrics (`score`, `q_number`), and perform input-to-state validation.
